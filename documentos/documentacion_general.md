# Documentación General: Gestión del Proyecto

Este documento describe la viabilidad, los objetivos y el presupuesto del sistema de Control de Accesos Biométrico.

## 1. Objetivo del Proyecto

El objetivo principal es la **automatización institucional del control de acceso** para eliminar la dependencia de métodos tradicionales como llaves físicas o bitácoras manuales.

**Beneficios Clave:**
- **Seguridad Incrementada:** Solo personal autorizado accede a las áreas asignadas.
- **Auditoría en Tiempo Real:** Registro digital de cada entrada y salida.
- **Eficiencia Operativa:** Reducción del error humano y tiempos de espera.

## 2. Análisis de Factibilidad

### Factibilidad Operativa
Sustitución total de métodos tradicionales por un flujo automático. El sistema es intuitivo tanto para administradores como para el personal docente, facilitando la adopción tecnológica.

### Factibilidad Técnica
El uso de hardware accesible (Tablets/Mini PCs) junto con servicios escalables de nube (Azure/AWS) asegura la disponibilidad y rendimiento del sistema. La arquitectura desacoplada permite futuras expansiones (ej: más aulas).

### Factibilidad Financiera
La inversión inicial estimada es de **$7,389 USD** para el despliegue de un aula piloto. El valor estratégico reside en la seguridad y el control de datos críticos de la institución.
